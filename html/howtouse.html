How To Use

Learn about some of the sensors used in an IoT monitoring system.

🌡️

Temperature Sensor

A temperature sensor measures the temperature of an area or device.

Example: Storage temperature can be monitored continuously.
💧

Humidity Sensor

A humidity sensor measures the amount of moisture in the air.

Example: The storage section can use humidity data to protect stored items.
🚶

Motion Sensor

A motion sensor detects movement inside a specific area.

Example: The garage can detect unwanted movement when it should be empty.
📏

Distance Sensor

A distance sensor measures how far an object is from the sensor.

Example: A robot can use distance information to detect objects in front of it.
🚗

Parking Sensor

A parking sensor can detect whether a parking position is occupied or available.

Example: The garage can report when the parking area becomes full.
📦

Object Sensor

Object detection sensors can identify or detect objects in a monitored area.

Example: The robot can report when an object is detected.
